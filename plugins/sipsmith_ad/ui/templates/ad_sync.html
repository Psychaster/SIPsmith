Step-by-Step: Configure CUCM LDAP Sync
  1. CUCM Administration → System → LDAP → LDAP System
    Enable LDAP Synchronization = ✓
    LDAP Server Type = Microsoft Active Directory
  2. CUCM → System → LDAP → LDAP Directory → Add New
    Fill values from the table above. Use the sync account DN and password.
  3. Set "LDAP User Search Base" = {{ base_dn }}
  4. Map "User ID" = sAMAccountName, and other attributes per the mapping table above.
  5. Click Perform Full Sync Now → users appear in End User list.
  6. If sync fails with SSL error: upload CA chain to CUCM tomcat-trust and directory-trust, restart Tomcat.
