Workflow Overview
  1. Define cluster — product, version, node FQDNs/IPs, enterprise domain(s)
  2. Generate plan — pack engine produces per-service cert requirements (SANs, EKUs, profiles)
  3. DNS preflight — verify A/PTR records exist for every SAN; SRV checks if MRA enabled
  4. Upload CSRs — generate CSRs on each product node and upload here; orchestrator validates SANs, key size
  5. Sign — CA plugin signs each CSR with the correct profile
  6. Deliver — download bundle zip with certs + CA chain + ordered checklist
  7. TLS probes — after upload on the product, run probes to confirm chain is valid
